# 0030. 문장 출처를 provenance.json의 `sentences`에 기록

- 상태: 채택
- 날짜: 2026-11-22
- 관련: FR-47, #144 (FR-21·FR-33·FR-36 위에 쌓음)

## 배경
FR-21은 숫자마다 출처를 `<결과 파일 이름>.provenance.json`의 `numbers`에 남긴다. FR-47은 도구가 만든
문장(보고서 요약·상세 줄, 할 일 표의 행)마다 근거 위치(엑셀 셀 범위, 회의록 문단)를 남기고,
studio에서 문장을 누르면 원본 탭에서 근거 위치를 보여 주며, 출처 없는 문장을 review_map이 짚어야 한다.

## 결정
같은 출처 파일에 `sentences` 목록을 추가한다. 항목은 `text`(문서에 보이는 문장 그대로)·
`location`(pptx는 `slide`·`shape`, xlsx는 `row`·`range`)·`source`(`file`과 `sheet`·`range` 또는
`paragraph`)다. 보고서 문장의 `source`는 같은 줄 숫자의 FR-21 출처(집계 방식·범위·조건)를 그대로 쓴다.
docx 문단 위치는 `word/document.xml`의 `w:p` 순번(0부터), hwp·hwpx는 본문 줄 순번(0부터)이다.

- 출처 파일을 다시 쓰는 도구(refresh_links·insert_range)는 `sentences`를 그대로 옮긴다.
  refresh_links는 숫자를 고친 뒤 같은 도형에서 숫자만 다른 줄로 `text`를 맞춘다.
- review_map은 `sentences` 키가 있는 pptx에서만 문장 검사를 한다. 대상은 본문 도형의 문단이며
  제목·부제목 개체 틀과 표·그래프는 뺀다. 문장 비교는 숫자를 `#`로 바꾼 모양으로 해,
  원본 값이 바뀌어 숫자만 달라진 문장은 같은 문장으로 본다. 숫자로 이미 걸린 문장은 한 번만 낸다.
- studio는 `/api/sentences`로 문장과 작업 폴더 기준 원본 경로·근거 위치 문구를 받아 보여 준다.
  문장을 누르면 원본 탭을 활성으로 만들고 탭 위 강조 줄(`data-role="source-highlight"`)에 근거 위치를 적는다.

## 검토한 대안
| 대안 | 장점 | 단점 | 버린 이유 |
| --- | --- | --- | --- |
| 문장 출처를 별도 파일(`.sentences.json`)로 | 기존 형식과 완전히 분리 | 파일이 둘로 늘고, 옮기거나 복사할 때 하나를 빠뜨리기 쉽다 | 출처는 한 파일로 다니는 편이 안전 |
| `numbers` 항목에 문장 텍스트를 덧붙이기 | 새 키 없음 | 한 문장에 숫자가 여럿이거나 숫자 없는 문장을 나타낼 수 없다 | 단위가 다르다 |
| ONLYOFFICE 편집기 안에서 셀 범위를 직접 선택 | 실제 셀이 강조된다 | 편집기 조작 API(connector)는 유료 판 기능이라 CI의 Community 판에서 쓸 수 없다 | 강조 줄로 대신한다 |

## 결과
- 숫자 출처와 문장 출처가 한 파일에 있어 기존 도구가 그대로 읽는다 (`numbers`만 보는 도구는 영향 없음).
- 문장 비교가 숫자를 무시하므로, 같은 도형에서 숫자만 바꾼 글은 출처 없음으로 잡지 않는다.
  사람이 문장 자체를 고치면 출처 없음으로 걸린다.
- ONLYOFFICE에서 셀을 직접 선택해 보여 주는 기능은 편집기 조작 API를 쓸 수 있게 되면 다시 본다.
