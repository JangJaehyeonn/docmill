# 0011. 레시피는 업무 도구 함수를 직접 호출해 실행한다

- 상태: 채택
- 날짜: 2026-11-15
- 관련: FR-10, ADR 0002, ADR 0010

## 배경
`run_recipe`는 저장된 레시피를 AI 없이, 같은 입력이면 같은 결과로 실행해야 한다.

## 결정
- 새 모듈 `docmill.runner`가 레시피 JSON의 단계를 순서대로 읽어 업무 도구 함수(`excel_to_report_ppt` 등)를 직접 호출한다. MCP 왕복이나 AI 호출은 없다.
- `$input` 변수에 실행 시 받은 입력 파일 경로를 넣는다. 값이 없는 변수는 실패한 단계와 함께 오류로 돌려준다.
- 단계가 하나라도 실패하면 즉시 멈추고 `N:도구(단계)` 형식으로 실패 위치를 돌려준다.
- 마지막 산출물을 `out_dir/<레시피 이름>.<확장자>`로 원자적으로 복사한다(`out_dir` 생략 시 도구의 기본 출력 위치).
- 서버는 `run_recipe`만 로그의 `ai_used`를 False로 기록한다. 호출 중 단계는 같은 실행 ID를 공유한다.

## 검토한 대안
| 대안 | 장점 | 단점 | 버린 이유 |
| --- | --- | --- | --- |
| MCP 클라이언트로 자기 서버 호출 | 경로가 동일 | 프로세스·왕복 비용, 로그 중복 | 불필요한 복잡도 |

## 결과
- 한 레시피에서 같은 도구를 여러 번 호출하면 기본 출력 파일명(실행 ID)이 겹칠 수 있다.
