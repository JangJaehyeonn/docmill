# 0028. 결재자별 기준은 이름별 JSON 파일로 저장한다

- 상태: 채택
- 날짜: 2026-11-19
- 관련: FR-43, [0009](0009-template-rules-storage.md), [0010](0010-session-recipe-recording.md)

## 배경
`register_reviewer`가 뽑은 결재자별 기준(길이·근거·결론 위치)을 다음 세션에서도 `rehearse_review`가 써야 한다.

## 결정
- 저장 위치: `DOCMILL_HOME/reviewers/<이름>.json`. 0009의 양식 규칙 저장과 같은 JSON 파일 방식이다.
- 이름 인코딩: `urllib.parse.quote(name, safe='')`. 경로 구분자가 파일명에 들어가지 않는다.
- 형식: `{"reviewer": 이름, "rules": [{"kind": "길이"|"근거"|"결론 위치", "source": 원문 코멘트, "limit": 장 수(길이만)}]}`. 종류 순서는 길이·근거·결론 위치로 고정한다.
- 쓰기: 임시 파일(`.tmp`)에 모두 쓴 뒤 교체해, 쓰기가 실패해도 이전 기준이 남는다.
- 같은 이름으로 다시 등록하면 기준을 통째로 바꾼다.

## 검토한 대안
| 대안 | 장점 | 단점 | 버린 이유 |
| --- | --- | --- | --- |
| SQLite 테이블 (0010의 세션 기록과 같은 저장소) | 한곳에 모임 | 규칙이 작고 사람이 직접 보기 어렵다 | 0009와 같이 파일이 더 단순하다 |

## 결과
- 새 의존성은 없다.
