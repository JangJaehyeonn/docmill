# 인수 기준 테스트 (보호 폴더)

이 폴더의 테스트는 요구사항 정의서의 **인수 기준**을 코드로 옮긴 것이다.
구현 PR이 통과해야 하는 기준이므로 다음 규칙을 지킨다.

- 이 폴더는 **사람(CODEOWNERS) 승인으로만** 바뀐다.
- Claude Code는 이 폴더를 수정하거나 테스트를 건너뛰게(`skip`, `xfail`) 만들 수 없다.
- 새 Phase가 시작되면 `acceptance-tests` 워크플로가 이 Phase의 테스트 초안을 만들고, 재현이 PR 하나로 한 번에 승인한다.
- 고정 샘플 파일은 `tests/fixtures/`에 둔다.

구현이 이 테스트를 통과하지 못하면 테스트가 아니라 구현을 고친다.
요구사항 자체가 잘못됐다면 이슈에 `needs-human` 라벨을 붙이고 멈춘다.
