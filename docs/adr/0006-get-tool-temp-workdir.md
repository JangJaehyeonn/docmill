# 0006. 어댑터 선택 함수와 임시 작업 폴더 소유

- 상태: 채택
- 날짜: 2026-11-14
- 관련: FR-03

## 배경
도구 코드가 확장자별 어댑터를 직접 고르면 엔진이 늘 때마다 고쳐야 한다. 작업별 임시 폴더는 반드시 정리되어야 한다.

## 결정
- `docmill.engines.get_tool(path, workdir=None)`이 확장자(대소문자 무시)로 어댑터를 고른다. 지원하지 않는 확장자는 `ValueError`.
- `workdir`를 주지 않으면 `get_tool`이 임시 폴더를 만들고 어댑터가 소유한다(`owns_workdir`). `close()`(`with` 종료, 오류 포함)가 엔진 종료 후 폴더를 지운다. 직접 준 폴더는 지우지 않는다.
- 어댑터 생성자는 여전히 작업 폴더를 필수로 받는다(FR-02).
- 같은 입력의 저장 결과가 같은지는 인수 테스트가 엔진 출력으로 검증한다.

## 검토한 대안
| 대안 | 장점 | 단점 | 버린 이유 |
| --- | --- | --- | --- |
| 호출자가 임시 폴더 관리 | 어댑터 단순 | 정리 누락 위험 | 요구사항(정리 보장) |

## 결과
- 호출자는 `with get_tool(path) as tool:` 한 줄로 격리와 정리를 얻는다.
