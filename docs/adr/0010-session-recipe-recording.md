# 0010. 레시피는 서버 세션 메모리에 성공한 호출을 모아 저장한다

- 상태: 채택
- 날짜: 2026-11-15
- 관련: FR-09, ADR 0002

## 배경
`save_recipe`는 "같은 세션에서 성공한 도구 호출"을 저장해야 한다. 실행 로그(SQLite)는 인자를 요약만 남기므로 재생용 인자를 얻을 수 없다.

## 결정
- 서버를 만들 때 `SessionRecorder`를 하나 만들고, 등록되는 업무 도구를 `recording`으로 감싼다. 결과 JSON에 `error`가 없는 호출의 원본 인자만 기록한다.
- `save_recipe(name)`은 기록을 `DOCMILL_HOME/recipes/<이름>.json`(`name`, `steps`: `tool`·`args`)에 원자적으로 저장한다.
- 입력 파일 인자(`input`·`document`·`source`)는 `$input` 같은 변수로 바꾼다. 같은 이름에 다른 경로가 오면 `$input2`처럼 번호를 붙인다. 환경에 따라 달라지는 `out_dir`은 저장하지 않는다.
- 저장할 성공 호출이 없으면 오류를 돌려준다.

## 검토한 대안
| 대안 | 장점 | 단점 | 버린 이유 |
| --- | --- | --- | --- |
| 실행 로그에서 재구성 | 프로세스 재시작에도 유지 | 인자가 요약·마스킹됨 | 재생 불가 |

## 결과
- 세션(프로세스)이 끝나면 기록은 사라지고, 저장된 레시피만 남는다.
