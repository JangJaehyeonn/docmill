# 0015. 원격 HTTP MCP 모드

- 상태: 채택
- 날짜: 2026-11-16
- 관련: FR-19, ADR 0001

## 배경
원격 MCP 클라이언트도 docmill 도구를 쓸 수 있어야 한다.

## 결정
`docmill mcp --http [--host H] [--port N]`은 같은 서버 객체를 MCP SDK의 streamable HTTP 전송으로 실행한다.
엔드포인트는 `/mcp`, 기본 주소는 `127.0.0.1:8000`이다. 외부 노출은 사용자가 `--host`로 명시할 때만 한다.
stdio가 기본이며 도구 등록은 두 모드가 동일하다. 새 의존성은 없다(SDK가 uvicorn을 포함).

## 검토한 대안
| 대안 | 장점 | 단점 | 버린 이유 |
| --- | --- | --- | --- |
| SSE 전송 | 구형 클라이언트 | 사실상 폐기 방향 | streamable HTTP가 표준 |
| 기본 0.0.0.0 | 편함 | 인증 없이 노출 | 안전 기본값 우선 |

## 결과
- 이 모드에는 인증이 없다. 외부 노출 시 역방향 프록시 등으로 보호해야 한다.
- 업로드 URL 파일 수신은 이 PR 범위 밖이며 이슈에 후속 제안으로 남긴다.
