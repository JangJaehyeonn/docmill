# 0002. 레시피는 엔진 명령이 아니라 docmill 도구 호출을 기록한다

- 상태: 채택
- 날짜: 2026-11-11
- 관련: FR-09, FR-10, FR-11, FR-12

## 배경
레시피의 목적은 "한 번 성공한 작업을 AI 없이 같은 형식으로 반복"하는 것이다.
매주 입력 엑셀의 행 수와 값은 바뀌므로, 셀 주소 단위 엔진 명령을 그대로 재생하면 범위가 어긋난다.

## 결정
- 레시피에는 `excel_to_report_ppt(input=$sales_xlsx, group_by="지역", ...)`처럼 **docmill 도구 호출과 인자**를 저장한다.
- 도구 내부 로직은 AI 없이 동작하는 일반 코드로, 같은 입력이면 같은 결과를 낸다.
- 실행 전에 필요한 열·시트를 점검하고, 실행 후 숫자 검증이 실패하면 결과를 내보내지 않는다.

## 검토한 대안
| 대안 | 장점 | 단점 | 버린 이유 |
| --- | --- | --- | --- |
| 엔진 명령 로그 재생 | 구현이 단순 | 입력 구조가 바뀌면 깨짐 | 재사용성이 없음 |
| 매번 AI에게 같은 프롬프트 재전송 | 유연 | 결과가 매번 달라지고 비용 발생 | 재현성·비용 목표와 반대 |
| 매크로·스크립트 코드 생성 | 결정적 | 비개발자가 관리하기 어려움 | 사용자 경험이 나쁨 |

## 결과
- 재실행은 AI 호출 0회, 형식 고정, 몇 초 이내가 된다.
- 레시피로 표현할 수 있는 범위는 docmill 업무 도구가 지원하는 범위로 제한된다.
